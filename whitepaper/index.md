# ROKO Network Whitepaper

**Public Release Draft v1.3 — 2026-07-22**

ROKO Network presents a Proof-of-Accurate-Time settlement layer for verifiable machine work: a Polkadot SDK and Frontier EVM-compatible layer 1 where validators measure time, sign temporal receipts, and route fees toward the validators that provide timestamping quality.

This public release draft integrates the Exa Group review feedback on reward-model clarity, pwROKO backing, and the planned migration path from the existing ERC-20 $ROKO token to native ROKO.
